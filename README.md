# Water Diplomacy Books

Static public website for
[waterdiplomacybooks.com](https://waterdiplomacybooks.com/), a catalog of
books on water diplomacy.

This repository is the GitHub Pages deploy repository. It contains only the
files needed to serve the public site. Agent instructions, harvest tools, and
open-access chapter PDFs are not published here.

## Contents

- `index.html` — catalog home (three open-access books, then other titles)
- `timeline/` — all titles by publication year
- `books/<id>/` — per-title pages (cover, publication info, publisher blurb)
- `assets/images/covers/` — harvested publisher jackets
- `data/catalog.json` — public catalog index
- `data/chapters/` — public chapter metadata for the 2012 and 2019 OA books
- `sitemap.xml`, `robots.txt`, `.nojekyll`, `404.html`

The *Routledge Handbook of Water Diplomacy* is catalogued here but lives on
its own site: [waterdiplomacyhandbook.com](https://waterdiplomacyhandbook.com/).
Chapter records for the 2012 and 2019 open-access titles link Taylor & Francis
DOIs; this repository does not host chapter PDFs.
